Server room build-out — dedicated, all-electric, cooled

actors: Mee · Bob · HQ  ·  date: 2026-10-14  ·  relation: resolves Node 02 & Node 03

The server now lives in a dedicated, all-electric room — not the basement. As built:

  • Cooling: a room heat pump, set cool enough for inlet air.
  • Air: a room filter in place (Node 02's filtration/positive-pressure intent).
